# 📓 Learning Journal

Relearning software engineering: not just writing code, but understanding how it runs, finding bugs, and fixing them.

## How this repo is organized
- One folder per language: `python/`, `sql/`, …
- Entries are numbered globally (001, 002, …) so the index reads in the order I learned things.
- Crossover entries list every language in the title, e.g. `[Python × SQL]`, and live in the main language's folder.
